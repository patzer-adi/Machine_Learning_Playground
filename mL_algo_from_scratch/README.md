# mL_algo_from_scratch

Simple implementations of common ML algorithms from scratch, organized as classes (object-oriented).

Contents:
- `knn.py` - K-Nearest Neighbors (classification/regression)
- `linear_regression.py` - Linear regression (closed-form and gradient descent)
- `gradient_descent.py` - small gradient descent helper
- `naive_bayes.py` - Gaussian Naive Bayes classifier
- `utils.py` - helper functions
- `examples/run_examples.py` - demonstrates usage on synthetic data

Requirements:
- numpy

Run examples:

```bash
python -m mL_algo_from_scratch.examples.run_examples
```
